# Письмо под звездопадом

Маленький сайт-письмо: ночное море, конверт с печатью, несколько экранов,
которые открываются касанием. Текст письма зашифрован — страница показывает
его только тому, кто знает имя и пароль.

Открывается в браузере, работает офлайн, зависимостей нет.

## Как устроено

`index.html` — вся страница целиком: разметка, стили, скрипт и зашифрованное
письмо. Ни картинок, ни аудиофайлов рядом нет:

- фон (звёзды, метеоры, море и блики на воде) рисуется в одном `<canvas>`;
- фонарики — элементы DOM с CSS-анимацией;
- мелодия синтезируется через Web Audio API прямо в браузере и запускается
  только по касанию — иначе мобильные браузеры её заблокируют.

## Как защищено письмо

Текст не лежит в файле открыто. Из имени и пароля выводится ключ
(PBKDF2-HMAC-SHA256, 310 000 итераций, случайная соль), им письмо
зашифровано алгоритмом AES-256-GCM. В `index.html` попадают только соль,
вектор инициализации и шифртекст — по ним прочитать письмо нельзя.
Расшифровка идёт в браузере через Web Crypto API; неверная пара
«имя + пароль» просто не даст ключ, и GCM отвергнет данные.

Это настоящая криптография, а не проверка пароля в скрипте, которую видно
в исходном коде. Но стойкость целиком упирается в пароль: шифртекст
общедоступен, поэтому короткий или очевидный пароль подбирается перебором.
Длинная фраза — обязательна.

## Счётчик

Страница может сообщать в GoatCounter о четырёх событиях:

| событие | когда |
|---|---|
| `/open` | страницу открыли |
| `/wrong-password` | неверное имя или пароль |
| `/unlocked` | письмо расшифровано |
| `/finale` | показан последний экран |

Уходит только имя события. Логин, пароль и текст письма в счётчик не
попадают никогда. Скрипт GoatCounter на страницу не подключается: пароль
вводится здесь же, а сторонний JS мог бы его прочитать. Вместо скрипта
отправляется обычный запрос-пиксель на `https://<код>.goatcounter.com/count`.

Включается кодом сайта в константе `COUNTER` в `template.html`, затем
`node build.mjs`. Пока строка пустая, счётчик ничего не отправляет.

Чтобы не считать собственные визиты, откройте сайт один раз с `?me` в конце
адреса. На этом устройстве счётчик отключится навсегда (флаг в
`localStorage`).

На claude.ai-версии счётчик не работает: политика безопасности блокирует
запросы на сторонние адреса.

## Как поменять текст

Плейнтекст письма лежит в `content.json`. Этот файл **не попадает в git** —
он перечислен в `.gitignore` и существует только на машине автора.

```
content.json   плейнтекст письма плюс поля _login и _password
template.html  страница без письма, с меткой /*VAULT*/
build.mjs      шифрует content.json и собирает index.html
index.html     результат сборки, только его и публикуем
```

После правок в `content.json`:

```sh
node build.mjs
```

Скрипт зашифрует письмо, вклеит его в шаблон, перезапишет `index.html` и
сам себя проверит — расшифрует результат обратно и сверит с исходником.
Если что-то не сошлось, сборка упадёт с ошибкой, а не выложит битый файл.

Требуется Node 18 или новее (нужен `webcrypto`).
